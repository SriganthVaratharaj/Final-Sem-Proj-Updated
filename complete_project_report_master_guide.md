      In the modern business environment, extracting structured data from commercial

Traditional Optical Character Recognition (OCR) systems systematically fail on real-world 
inputs due to non-standardized layouts, physical paper degradation, and widespread 
code-switching across Indian regional scripts. Legacy pipelines depend on sequential text 
box detection and text recognition, causing early bounding-box errors to propagate downstream, 
requiring extensive manual entry. 

      To overcome these limitations, this project introduces a Multimodal Document Intelligence 
System (MDIS) operating on an OCR-free, pixel-level visual extraction paradigm. The system

text steps by directly interpreting spatial layouts and native script elements at the pixel level. 
A localized Contrast Limited Adaptive Histogram Equalization (CLAHE) stage restores faded 
thermal ink, while an aspect-ratio preserving vertical overlap splitting algorithm processes 
tall document slices within visual token capacities.

      To eliminate local computing constraints, a distributed Master-Worker architecture is 
implemented. A lightweight FastAPI master node handles local preprocessing and serialized prompt 
packaging. Encrypted Cloudflare Tunnels securely route payloads to remote dual NVIDIA T4 GPU workers 
running the 32B model with IQ4 XS 4-bit quantisation for high-speed inference. A Chain-of-Thought 
(CoT) dual-prompt extracts regional characters and parallel English translation fields in a single forward 
pass, while a monospace ASCII grid "Digital Twin" output provides spatial document layout 
reconstruction for immediate human auditing.

      On a diverse Indic financial document corpus, the proposed system achieves a Key-Value 
Accuracy of 96% on invoices and 92% on degraded receipts. This approach outpaces traditional 
OCR-based baselines, significantly decreases transaction latency, and delivers a scalable, 
cost-effective document parsing system for automated business accounting workflows.

INTRODUCTION

      In modern enterprises, automated document processing plays a critical role in 
accounting, auditing, and supply chain operations. However, real-world documents, 
especially in the Indian context, are highly unstructured and often contain multilingual 
text, inconsistent formatting, and degraded visual quality. 

      Traditional Optical Character Recognition (OCR) systems attempt to solve this 
problem using a two-stage pipeline: first, detecting text regions through bounding box 
localization, and second, recognizing the textual content within those regions. While this 
approach works reasonably well for clean, well-formatted documents, it struggles in real-
world conditions. Errors in text detections—such as missing or incorrectly segmented 
regions—propagate to the recognition stage, resulting in incorrect or incomplete outputs. 
Furthermore, OCR systems lack an inherent understanding of document structure and 
context. They often fail to preserve relationships between key elements, such as 
associating item names with their corresponding prices in a receipt, leading to loss of 
semantic meaning. 

      To overcome these challenges, this project introduces a Vision-Language Model (VLM)-
based system that fundamentally redefines the document processing pipeline. Instead of 
relying on intermediate text extraction steps, the proposed approach directly interprets 
document images at the pixel level and generates structured outputs in formats such as 
JSON. By leveraging advanced multimodal learning, the system simultaneously captures 
both textual content and spatial relationships within the document. This enables a deeper 
contextual understanding, allowing the model to accurately identify key-value pairs, 
tabular data, and hierarchical structures without explicit layout rules.  

1.1 OBJECTIVE
      The main objective of this research is to develop an efficient and intelligent 
Multimodal Document Intelligence System capable of accurately extracting structured 
information from complex, real-world financial documents such as invoices and receipts. 
The system aims to overcome the limitations of traditional OCR-based approaches by 
leveraging advanced Vision-Language Models (VLMs) for direct image understanding 
and structured data generation.

1.2 AIM
     The aim of this project is to design and implement an advanced Multimodal Document 
Intelligence System that can efficiently process and understand complex financial 
documents such as invoices and receipts. The system aims to utilize Vision-Language 
Models (VLMs) to directly interpret document images and generate structured outputs 
without relying on traditional OCR pipelines. It focuses on achieving high accuracy, 
layout awareness, and multilingual understanding, enabling reliable extraction of key

4.2 PROPOSED METHOD
To overcome the severe limitations of legacy OCR-based document parsing pipelines, this work proposes a Multimodal Document Intelligence System (MDIS) that operates on an OCR-free, pixel-level extraction paradigm. The core intelligence is driven by the Qwen2.5-VL-32B Vision-Language Model (VLM), which interprets the layout and text directly from visual features using a gated cross-attention transformer decoder. The proposed system features an advanced preprocessing workflow utilizing Contrast Limited Adaptive Histogram Equalization (CLAHE) for degraded receipts, a dynamic resolution-preserving overlap splitting algorithm for tall documents, and a Chain-of-Thought (CoT) dual-language prompt execution mechanism that extracts native script text and translated English fields simultaneously.

To bypass local hardware limitations, the proposed system employs a distributed Master-Worker architecture. A local, lightweight FastAPI server (Master Node) manages image acquisition and preprocessing, while secure Cloudflare Tunnels dynamically route quantised tensor calculations to remote dual NVIDIA T4 GPU workers (Worker Node). The final extraction yields structured, schema-validated JSON outputs alongside a monospace-aligned "Digital Twin" text-grid representation, which enables spatially faithful document visualization for human auditing without the need for frontend coordinate bounding-box rendering.

4.2.1 Key Features of the Proposed Method
• OCR-Free End-to-End Visual Extraction
The system bypasses OCR engines entirely by processing raw document image patches. This eliminates character recognition and bounding box detection error propagation paths, substantially improving accuracy on skewed, noisy, or degraded inputs.

• Contrast Limited Adaptive Histogram Equalization (CLAHE)
Rather than relying on binarisation, which amplifies crease noise, the preprocessing pipeline applies localized adaptive contrast enhancement to make faded thermal inks highly legible before visual patch tokens are generated.

• Dynamic Overlap Splitting Algorithm
To prevent visual token budget overflow on tall thermal receipts, the system dynamically slices images along the vertical axis with an overlap margin (delta), guaranteeing that text lines intersecting chunk boundaries are captured in their entirety by at least one adjacent patch.

• Gated Cross-Attention Multimodal Fusion
The VLM architecture integrates visual patch embeddings directly into the layers of the 32-billion parameter language decoder through gated cross-attention. This enables the system to capture spatial key-value dependencies (such as row-to-price mapping in borderless tables) regardless of structural irregularities or overlapping merchant stamps.

• Chain-of-Thought (CoT) Dual-Language Translation
The prompt execution layer utilizes a two-pass CoT strategy: the model is instructed to first transcribe the document exactly in its native regional script, and then output an aligned, English-translated JSON payload in a single forward pass, eliminating downstream API translation delays.

• Spatially Faithful Digital Twin Verification
The VLM is prompted to reconstruct the document as a monospace ASCII grid. This Digital Twin acts as a spatial layout representation, allowing human-in-the-loop auditors to instantly inspect alignment accuracy without navigating nested JSON trees.
